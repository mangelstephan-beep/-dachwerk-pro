## Umgesetzt

Modul 08 zeigt unter „EFB-Preis 221 / 222 / 223 – Übertragungshilfe“ die Werte für die Formblätter aus der aktuellen Kalkulation des Projekts. Jedes Blatt lässt sich auf dem DachWerkPro-Briefpapier drucken; EFB 223 zusätzlich als CSV. Maßgeblich bleibt das Formblatt aus den Vergabeunterlagen des Auftraggebers.

### Feldzuordnung

| Formblatt / Zeile | Quelle in DachWerkPro |
|---|---|
| 221 · 1.1–1.3 Mittellohn, lohngebundene Kosten, Lohnnebenkosten | nicht getrennt erfasst → aus Lohnkalkulation (Modul 03) übertragen |
| 221 · 1.4 Kalkulationslohn | globaler Stundenkostensatz bzw. Kalkulationslohn der Kostenartenzuschläge |
| 221 · 1.5 / 1.6 Zuschlag, Verrechnungslohn | Gesamtzuschlag Lohn; VL = KL × (1 + Zuschlag) |
| 221 · 2.1 BGK | 0 % (projektbezogene Gemeinkosten sind nicht im EP enthalten) |
| 221 · 2.2 AGK / 2.3 W+G | globale Sätze; W+G auf Einzelkosten bezogen = Gewinn × (1 + AGK), damit 2.2 + 2.3 = 2.4 |
| 221 · 2.4 Gesamtzuschlag | (1 + AGK) × (1 + Gewinn) − 1 bzw. Kostenartenzuschlag; NU mit eigenem Zuschlag |
| 222 · Einzelkosten | Lohn (Stunden × KL), Stoffe, Geräte, Sonstige, NU – ohne Bedarfs- und Alternativpositionen |
| 222 · Umlage / Angebotssumme | Angebotssumme netto minus Einzelkosten |
| 223 · OZ, Kurzbezeichnung, ME, Zeitansatz | Positionsnummer, erste Textzeile, Einheit, Minuten / 60 |
| 223 · Lohn, Stoffe, Geräte, Sonstiges, EP | Teilkosten je Einheit inkl. Zuschläge; NU unter Sonstiges, zusätzlich ausgewiesen |

### Regeln

- Die Aufgliederung in EFB 223 ergibt **exakt** den angebotenen EP. Zielpreis und Rabatt werden anteilig auf die Kostenarten verteilt; ein Rundungscent wird im größten Anteil ausgeglichen und in der Spalte „Hinweis“ genannt.
- Uneinheitliche Zuschläge, unterschiedliche Kalkulationslöhne oder gemischte Kalkulationsarten werden als „Vor dem Übertragen klären“ angezeigt. EFB 221 bleibt dann an den betroffenen Stellen leer (—), statt einen Mittelwert zu erfinden.
- Positionen mit EP, aber ohne Einzelkosten werden gemeldet.
- Bei Kostenartenzuschlägen wird nur der Gesamtzuschlag ausgewiesen; die Aufteilung auf BGK, AGK und W+G trägst du selbst ein.

## Abnahme-Checkliste (HP und iPhone)

1. Testprojekt mit zwei bis drei kalkulierten LV-Positionen öffnen, Modul 08 aufrufen ([Live](https://www.dachwerkpro.de/?start=app&module=efb)).
2. EFB 221: Kalkulationslohn und Zuschläge stimmen mit den Betriebsdaten bzw. den Kostenartenzuschlägen überein.
3. EFB 223: Für jede Position ergibt Lohn + Stoffe + Geräte + Sonstiges den EP aus der Kalkulationsübersicht.
4. Bei einer Position einen Zielpreis setzen → EFB 223 verteilt ihn anteilig, Hinweis „Zielpreis anteilig …“.
5. „EFB 223 drucken“ → Druckvorschau mit Briefkopf; „EFB 223 als CSV“ → Datei lässt sich in Excel öffnen.
6. Mit einem echten Formblatt aus Vergabeunterlagen vergleichen: Zeilen und Spalten passen, fehlende Angaben (Mittellohn) sind erkennbar.
